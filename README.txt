Govind's Study Hub — Semester 1

HOW TO USE
1. Extract this folder from the ZIP.
2. Keep index.html and all four *-qa.html files in the same folder.
3. Double-click index.html to open the Study Hub in Edge or Chrome.
4. Search by subject/course code and click Open Q&A.

FILES
- index.html: Semester 1 subject list with modules and Q&A links.
- maths-qa.html: GYMAT101 coach (question bank based on uploaded source).
- eee-qa.html: GXEST104 coach (question bank based on uploaded source).
- physics-qa.html: GBPHT121 coach (question bank based on uploaded source).
- python-qa.html: UCEST105 coach (question bank based on uploaded source).

Engineering Graphics and CAD (GMEST103) is listed with its modules, but no Q&A page was uploaded/created in this bundle yet.
The Q&A files preserve the attached coach content and existing interactive functionality.
